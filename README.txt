# T26 for Windows

A two-mode Windows launcher package for T26.

[Download v1.0.0](../../releases/latest) · [Quick Start](#quick-start) · [Optional Local AI](AI-SETUP.md)

![T26 launcher screenshot](docs/images/t26-launcher.png)

## Quick Start

1. Download and extract the release ZIP.
2. Run `Launch-T26-Standard.cmd` for normal use.
3. Use `Launch-T26-Developer.cmd` when you need the developer configuration.
OPTIONAL LOCAL AI SETUP

Run Setup-T26-LocalAI.ps1 to inspect local hardware, reuse an installed Ollama model, or receive a conservative LIGHT/BALANCED/ADVANCED recommendation. Any model download and any inference probe require explicit tester approval. The assistant never bundles model weights and does not silently change T26 configuration.

See AI-SETUP.md for details. Runtime AI behavior remains subject to the tester's local Ollama installation, model availability, hardware, and independent acceptance testing.
